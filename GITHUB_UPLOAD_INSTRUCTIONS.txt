HENOSIS 2.0 — ADD PHOTOS AND PUBLISH

1. Extract the ZIP.
2. Open a terminal inside the extracted folder.
3. Run: python3 download_photos.py
4. Confirm these files exist: assets/anu.jpg, assets/enlil.jpg, assets/enki.jpg, assets/nabu.jpg
5. On GitHub, open https://github.com/Vladik-Dracovich/henosis
6. Choose Add file > Upload files and upload the CONTENTS of this folder, including assets/ and the four JPGs.
7. Commit changes. Pages must publish main / (root).

No pip or Pillow required. If a photograph fails, the script prints FAILED and you should retry before uploading.
