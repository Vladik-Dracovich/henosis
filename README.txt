HENOSIS v1.4

1. Unzip the archive.
2. Install Pillow if needed: python3 -m pip install --user Pillow
3. Run: python3 download_photos.py
4. Run: python3 -m http.server 8000
5. Open http://localhost:8000 in Firefox.

The downloader stores four resized photos in assets/. The site falls back to remote Wikimedia image links until these files exist. Downloaded photos are not included in this archive because the build environment could not fetch image bytes.

See PHOTO_CREDITS.txt for image credits and licensing.
